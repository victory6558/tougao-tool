# tougao-tool（投稿工具台）

一款面向小说作者的 **Windows 本地投稿工作台**：把发件邮箱、编辑名单、作品信息、投稿计划、发送记录、来信回复和过稿统计集中在一个窗口里，让批量投稿有节奏、有记录、可复盘。

数据只保存在你自己的电脑上，不上传任何服务器。

## 功能一览

### 投稿流程管理



* **工作台总览**：今日投递、人工回复、过稿回复、失败记录一屏查看；近 7 / 30 天投递与回复趋势图；最新来信、下载历史快捷入口。

* **投稿计划**：分步填写作品与邮件、选择收件人和发件邮箱；支持文稿附件、计划复制、草稿保存与投递详情查看；内置多套通用邮件模板，可固定选用或随机轮换。

* **发送调度**：支持立即发送、指定时间开始、在上一个计划结束后延迟发送；每封邮件按设置的最短 / 最长间隔随机等待；后台定时检查，主窗口最小化或隐藏后任务继续执行。

* **发送记录**：按计划、发送结果、邮箱检索；失败原因可查看；支持暂停、继续、停止与失败重试；记录可导出。

### 邮箱与编辑



* **邮箱管理**：管理多个 SMTP / IMAP 发件邮箱、笔名与备注；自动识别 QQ、163、126、Yeah 等邮箱的服务器参数，也可手动调整；支持连通性测试。

* **编辑库**：按收稿 / 拒收类型、平台、收藏、启用状态和拉黑关系筛选；可直接编辑资料、查看回复情况；支持 Excel / CSV 导入导出与编辑组管理。

* **内置编辑名单**：随包附带 257 位常投编辑资料（覆盖 130 个平台），可自行增删改，也可以清空后只用自己的名单。

### 来信与统计



* **收件箱**：汇总多个账号的来信，区分人工回复、自动回复与退信；左右分栏阅读，支持 HTML / 纯文本、引用折叠、附件保存、搜索与已读同步。

* **过稿核对**：从待核对邮件进入原文核验，记录过初审、最终过稿、未过终审或未过稿；支持误判处理、原稿查看，以及买断 / 保底分成 / 平台月结、千字计价等稿酬记录。

* **数据统计**：按日 / 周 / 月查看投递量、人工回复率、过稿回复与失败情况的趋势和明细。

### 内置辅助工具



* **榜单查询**：长篇 / 短篇两类，按平台与榜单查看书名、作者、简介、字数与在读数据；分类与刷新由本机引擎完成，不依赖第三方在线服务。

* **小说下载**：按书名 / 作者检索并离线下载小说，保存到独立目录；下载引擎内嵌在主程序内，与投稿数据完全隔离，出错不影响投稿功能。

* **短篇写作知识库**：2876 条爆款导言（按赛道 / 背景 / 平台 / 作者检索、可复制）、12 种结构骨架、金句库与人设对库、书名＋导言生成指令、7 份作者文风档案与去 AI 味提示词；全部随包放在本机，离线可用。

### 界面与设置



* 多套配色主题可随时切换，切换后立即生效并自动保存。

* 回复检查、开机自启、关闭到托盘、数据备份、空间用量查看与缓存清理。

* 右下角独立进度浮标：投稿进行中显示实时进度与状态，点击即可唤回主窗口。

## 下载与安装

### 环境要求



* Windows 10 / 11，64 位系统。

* WebView2 运行时（现代 Windows 一般已自带；缺失时安装过程会提示安装引导）。

### 安装步骤



1. 进入本仓库的 **Releases** 页面，下载最新版本的 `tougao-tool_0.2.18_x64-setup.exe`。

2. 双击安装包，按提示完成安装。

3. 启动后先在「邮箱管理」添加发件邮箱，再按下面的流程开始投稿。




***

## 快速上手



1. **添加发件邮箱**：进入「邮箱管理 → 添加邮箱」，填写完整邮箱地址和 SMTP 授权码、笔名；服务器参数会按域名自动填好，可先点测试连接。

2. **维护编辑名单**：在「编辑库」查看内置名单，按平台和收稿类型筛选；不需要的编辑可以禁用或删除，也可以导入自己的 Excel / CSV 名单。

3. **创建投稿计划**：进入「投稿计划」，填写作品信息、邮件模板和附件，选择收件人与发件邮箱，设置发送时间和间隔。

4. **跟进回复**：投稿后在「收件箱」查看来信，人工回复、自动回复和退信自动分类；在「过稿统计」里核对并记录过稿与稿酬。

## 邮箱授权码说明

QQ、163、126、Yeah 等邮箱需要填写 **SMTP 授权码**，不是网页登录密码：



* **QQ 邮箱**：登录 [mail.qq.com](https://mail.qq.com) →「设置 → 账号」→ 找到 POP3/IMAP/SMTP/Exchange 服务 → 开启 IMAP/SMTP 服务 → 手机短信验证后生成授权码。

* **163 / 126 / Yeah**：分别登录 [mail.163.com](https://mail.163.com)、[mail.126.com](https://mail.126.com)、[mail.yeah.net](https://mail.yeah.net) →「设置 → POP3/SMTP/IMAP」→ 开启客户端服务 → 短信验证后复制客户端授权码。

授权码仅加密保存在本机系统凭据中，不会上传到任何服务器。详细步骤在应用内「邮箱管理 → 添加邮箱」面板里也有说明。

## 数据与隐私



* 所有投稿资料、作品、计划、发送记录、来信缓存和稿酬记录都保存在本机 SQLite 数据库中。

* 发件邮箱授权码写入 Windows 凭据管理器；钥匙串不可用时才会降级保存并在界面提示。

* 程序不会把你的投稿内容、邮箱或来信上传到外部服务器。

## 使用注意事项



* 请遵守各邮箱服务商的发送规则，合理设置每日发送上限和发送间隔，避免被限流或冻结。

* 榜单查询与小说下载的结果来自公开站点，站点改版或接口变动时相关功能可能暂时不可用。

* 投稿邮件内容、投稿对象与发布行为由使用者自行负责；过稿 / 退信识别结果仅供提示核对，最终以人工核实为准。

* 应用需保持运行、电脑唤醒且处于联网状态，定时任务才会按时执行；电脑休眠期间错过的预约会在恢复后补发或标记错过。
